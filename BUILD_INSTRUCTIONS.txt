BUBBLE BOT — FREE LOCAL ANDROID TEST BUILD

1. Install the latest stable Android Studio:
   https://developer.android.com/studio

2. Android Studio > File > New > New Project > Empty Views Activity.
   Language: Java. Minimum SDK: API 26. Name: BubbleBot.

3. Close the new project.

4. Replace the generated project source/build files with the files in this ZIP.
   Keep the Gradle wrapper files generated by Android Studio if present.
   The source is configured for Android Gradle Plugin 9.0.1 / Gradle 9.1 and compileSdk 36.

5. Open the BubbleBot folder in Android Studio and allow Gradle Sync.

6. OpenCV 4.13.0 is a Maven Central dependency. Gradle downloads it during the first build.
   The bot itself does not need internet while playing.

7. Build > Make Project.

8. Connect the Android phone by USB, enable Developer Options + USB debugging, then press Run.
   Or use Build > Build App Bundle(s) / APK(s) > Build APK(s), then install the debug APK.

9. On the phone:
   - Open Bubble Bot.
   - Tap "1 — Enable Accessibility".
   - Enable Bubble Bot under Accessibility.
   - Return to Bubble Bot.
   - Tap "2 — Start Bot / Screen Capture".
   - Approve Android's screen-capture permission.
   - Open the game.

10. The bot analyzes the board locally and sends touch gestures through AccessibilityService.

IMPORTANT LIMITATIONS OF THIS FIRST BUILD:
- Tuned to the 588x1280 portrait game layout in the supplied video.
- Uses OpenCV Hough-circle detection, HSV color classification, board connectivity/drop simulation,
  and direct/one-wall-bounce shot selection.
- Assumes the game shoots toward a tap position.
- Power-up buttons are not automatically activated because their exact activation rules were not
  unambiguously visible in the supplied footage.
- If the game's tap/shoot behavior differs on your phone, the firing method in GameAnalyzer.java
  needs a small adjustment.
